# Hotel state manager

När programmet startas, måste användaren logga in. När använaren
har loggat in, navigerar användaren i menyn genom att skriva in
siffror som motsvarar det användaren vill göra. kontot ligger sparat
på fil och laddas när programmet startar. rummen ligger också sparat
på fil och laddas när programmet startar, men uppdateras också när
användaren utför ändringar.

om användaren väljer 1 så får användaren fram en lista på upptagna rum.

om användaren väljer 2 så får användaren fram en lista på lediga rum.

om användaren väljer 3 så får användaren en lista på lediga rum och får sedan
    välja vilket rum de vill boka, sedan namnet på gästen som ska bo där.

om användaren väljer 4 så får användaren en lista över upptagna rum och får
    välja vilket rum de vill checka ut och sedan markera som tillgängligt igen.

om användaren väljer 5 så får användaren en lista över alla rum och kan sedan
    välja att markera tillgängliga rum som otillgängliga eller markera ett
    otillgängligt rum som tillgängligt genom att skriva in rumsnummret.

om användaren skriver in "L" eller "l" så loggas användaren ut från kontot.

om användaren skriver in "Q" eller "q" så stängs programmet.
